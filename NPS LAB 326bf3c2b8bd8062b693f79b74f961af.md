## Program Descriptions

### Prog 1 – TCP File Transfer
Client sends a filename; server opens and streams the file contents back over TCP.  
Port: **15001**

### Prog 2 – Distance Vector Routing
Bellman-Ford algorithm simulated for N routers.  
Input: cost matrix (use `999` for no link). Output: each router's next-hop table.

### Prog 3A – IP Checksum
Sender computes 1's-complement checksum of 10 IP header fields.  
Receiver verifies: result `0x0000` → no error.

### Prog 3B – Hamming Code (7,4)
Encodes 4 data bits into a 7-bit Hamming codeword.  
Detects and corrects any single-bit transmission error using syndrome bits.

### Prog 4 – UDP Multicast
Sender broadcasts `RVCE-CSE` to multicast group `225.0.0.37` every second.  
Any receiver that joins the group receives the message. Port: **12345**

### Prog 5 – Concurrent Chat Server
Server forks a child process per connected client.  
Client sends a message; server operator types a reply. Port: **15001**

### Prog 7 – Remote Command Execution
Client types shell commands; server echoes them back and executes via `system()`.  
Port: **15001**

### Prog 8A – Diffie-Hellman
Alice and Bob exchange public keys and derive the same shared secret without transmitting private keys.

### Prog 8B – RSA
Randomly picks primes `p`, `q`; generates public/private key pair; encrypts and decrypts a string using modular exponentiation.
